# 05 · 踩坑清单

按「症状 → 原因 → 解法」记，都是这个项目真实踩过的。

## 视觉

| 症状 | 原因 | 解法 |
|---|---|---|
| 立绘被裁成圆形头像 | 用 `ctx.clip()` 画圆来做角色 | 碰撞体和视觉分离：完整立绘 + 不可见圆做判定 |
| 两个角色一个大一圈 | 按**图片画布**缩放，两张原图尺寸差很多 | 按 `alpha>60` 求主体包围盒，只对齐主体高度 |
| 小字号汉字糊成黑块 | 15px 汉字直接放大 + 抗锯齿 | 20×20 离屏画布超采样 + `imageSmoothingEnabled=false` |
| 每帧都在建画布，掉帧 | 每次发射都重新绘制文字 | 按 `字+颜色` 缓存 canvas，之后只做 blit |
| 像素爱心糊成方块 | `shadowBlur` 给到 16px | 发光收到 ≤6px，每格先描深色轮廓再填色 |
| 血条格子数不清 | 角色变小后按 `2r` 排 15 格，每格 3px | 血条宽度取下限 `max(2r, min(W,H)*0.22)` |
| 冲击波「看不见」 | 0.42 范围 + 0.55 速度 = 0.76s 一闪而过 | 范围和速度一起调（0.58 / 0.64 ≈ 0.91s） |
| 追踪弹看不出在追踪 | 距离近时 0.14s 命中 | 加 0.28s 起飞窗口，前段只飞不判定 |

## 玩法

| 症状 | 原因 | 解法 |
|---|---|---|
| 一句台词都没吐完就倒地 | 用「命中冷却」而不是「受击无敌」 | `HIT_CD` 改成受击后 0.55s 无敌，命中率降到 ~43% |
| 命中率太低，看着像乱打 | 只朝目标当前位置开火 | 按目标速度做提前量（`AIM_LEAD=0.6`）+ ±8° 散射 |
| 冲击波太强，一放必死 | 弹飞撞墙又扣一格 | 撞墙只给火花/震屏，不额外扣血 |
| 大招太密，画面看不清 | 冷却设太短 | 冲击波 6s、爱心炮 5s，叠在吐字弹幕之上 |
| 眩晕结束后 CD 立刻好 | CD 在眩晕期间继续走 | 眩晕时暂停 CD 递减，眩晕结束后顺延 |

## 工程

| 症状 | 原因 | 解法 |
|---|---|---|
| 探针页全是 `NO PROBE` | 注入锚点不再唯一 | `assert base.count(anchor) == 1`，改模板时立刻暴露 |
| 模拟跑出 `elapsed=0` | 虚拟时间下 rAF 不推进 | 探针模式手动 `step(h)` 循环，不依赖 rAF |
| 页面卡死白屏 | 无头环境 `decodeAudioData` 不 resolve | 探针页给 `AudioContext.prototype.decodeAudioData` 打桩 |
| 第二个浏览器进程立刻退出 | 复用了同一个 `--user-data-dir` | 每次跑用唯一 profile 目录 |
| 录出来是默片 | 无头浏览器走音频兜底，音轨为空 | 必须用**有头**浏览器录制 |
| 录到 7.3 秒画面定格 | 窗口没焦点，rAF 被节流 | `--kiosk` 全屏 + `--disable-features=CalculateNativeWinOcclusion` |
| 录制只有 630×473 | 画布 CSS 宽 420、dpr 上限 2 | 注入 `.stage{width:640px!important}` → 960×720 |
| 用 `--force-device-scale-factor=2` 掉帧 | 渲染负担翻倍，掉到 17fps | 放弃，改用放大画布 |
| 改完玩法视频时长不够 | 节奏变慢但录制秒数没改 | 先跑 6 局探针拿到新的倒地时间，再定录制时长 |
| ffmpeg 报 `height not divisible by 2` | 473 是奇数 | `-vf scale=630:472` |
| ffmpeg 写不出中文文件名 | shell/编码问题 | `... -f mp4 pipe:1 > out.mp4`，抽帧同理 |
| `ffprobe` 读不到 WebM 时长 | MediaRecorder 产出的 WebM 没有 duration | 用 `nb_read_packets ÷ avg_frame_rate` 推算 |

## 流程

- **改比例/改名字要三处同步**：CSS `aspect-ratio`、文件名、导出名。改完 `grep` 一遍旧值确认无残留。
- **动手前先问清手感**：技能叠加方式、释放频率、撞墙是否额外扣血——这三个问题定不下来，
  后面所有数值都要重调。
- **每轮改动都跑「构建 → 语法 → 探针 → 截图」四步**，成本一条命令，比事后 debug 便宜得多。
