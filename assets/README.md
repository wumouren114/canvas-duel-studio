# assets/ 素材说明

本目录**不包含**任何人物立绘与音乐文件。请放入你有权使用的素材。

## 需要的文件

| 文件名 | 说明 | 建议 |
|---|---|---|
| `p1.png` | 红队（左侧）立绘 | 透明背景 PNG，主体居中，高度 ≥ 800px |
| `p2.png` | 蓝队（右侧）立绘 | 同上 |
| `bgm.mp3` | 循环播放的对局 BGM | 建议先剪成 20~40 秒的循环段 |
| `end.mp3` | 倒地后播放的曲子 | 建议 10~20 秒，开头就是想要的高潮句 |

背景透明很重要：`build_scene.py` 用 `alpha > 60` 求主体包围盒，
不透明的图会被判定为「整张图都是主体」，视觉大小对齐就失效了。

## 想用自己的文件名

不用改名，用环境变量指过去即可：

```bash
DUEL_P1=/path/to/hero_red.png \
DUEL_P2=/path/to/hero_blue.png \
DUEL_BGM=/path/to/bgm.mp3 \
DUEL_END=/path/to/end.mp3 \
python tools/build_scene.py
```

## 尺寸/格式说明

- 立绘会被压到最长边 640px、转 WebP（质量 90），所以原图给 1000~1500px 足够，再大只是白占体积。
- 音乐按原始字节 base64 内嵌，**体积直接加进 HTML**。两首各 40 秒 128kbps ≈ 1.2MB，
  想控制产物体积就先压到 96kbps 或剪短。
- 换素材后必须重新跑 `python tools/build_scene.py`，否则 HTML 里还是旧图（内嵌副本，不是链接）。
